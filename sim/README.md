# 태그 비행 시뮬레이터 (보드 연결형)

드론 없이 **실제 XIAO 보드의 카메라와 펌웨어**로 미션 전체를 시험한다.

```
 브라우저: 가상 드론 물리 → 화면에 태그를 "드론 카메라에 보일 위치·크기"로 그림
     ▲                                         │
     │ 스틱 값 rc (USB, 20Hz)                   ▼ XIAO 카메라가 화면을 봄
 XIAO 보드: 실제 태그 인식 → 판단 → 스틱 값      (가상 고도는 simh 로 전달)
```

## 준비

1. 보드에 `TAGVISION-20261003-05` 이상을 올린다. 시뮬레이션 모드가 이 버전부터, 블루투스는 `-07`부터 들어 있다.
2. 로컬 서버로 연다. Web Serial은 Chrome·Edge에서만 되고, claude.ai 같은 외부 페이지 안에서는 동작하지 않는다.
   ```bash
   python3 -m http.server 8000 -d sim
   # Chrome 에서 http://localhost:8000
   ```
3. XIAO 카메라를 화면 **왼쪽 흰 영역 중앙**에 25~35cm 거리로 고정하고, 화면 밝기를 최대로 둔다.

## 사용 순서

1. **USB 연결** 또는 **블루투스 연결**을 누른다.
   - USB: Espressif 장치만 목록에 나오므로 FC(INAV) 포트에 잘못 연결될 일은 없다. 연결하면 보드가 재부팅된다.
   - 블루투스: `TagBoard-XXXX`만 목록에 나온다. 재부팅이 없고, 보드를 FC 5V 전원으로 켠 상태에서도 쓸 수 있다.
2. **카메라 화면 보기**로 카메라가 흰 영역을 보는지 확인한다.
3. **자동 보정**을 누른다. 태그를 세 곳에 그려 카메라 회전·반전·중심 어긋남을 구하고, 브라우저에 저장한다. 카메라를 옮기면 다시 한다.
4. **리셋 → 시작**을 누르면, 보드가 태그를 보고 정렬 → 50cm → 3초 유지 → 100cm → 호버링 미션을 수행한다.

## 시험해 볼 상황

| 조작 | 확인할 것 |
|---|---|
| 바람 세기·방향 | 바람에 밀려도 착륙 지점으로 돌아오는지 |
| 돌풍 | 순간적으로 밀렸을 때 흔들림 없이 복귀하는지 |
| 태그 가리기 | 보드가 태그를 놓치면 스틱이 중립(1500)이 되고 단계가 멈추는지 |
| 보드 MSP 끊기 | 약 0.8초 뒤 INAV가 조종기 입력으로 돌아가는지 (보드가 멈춘 상황) |
| 조종권: 조종기 | AUX 스위치를 내린 상황. 보드 명령이 무시되는지 |
| ANGLE 모드 | 스틱이 기울기를 뜻하는 모드. 지금의 P 제어만으로는 진동한다 → 실기는 POSHOLD를 권장 |
| 1m 고도 태그 크기 | 값이 클수록 낮은 고도에서 태그가 화면 밖으로 빨리 나간다 (실기의 "너무 가까움" 상황) |

## 모델 가정 (단순화)

- **POSHOLD:** 스틱은 목표 속도(최대 7.5m/s, 이 FC의 `nav_manual_speed`)다. 바람은 FC가 85% 상쇄한다고 본다. **현재 FC에는 위치 센서가 없어 NAV POSHOLD 모드가 나오지 않는다.**
- **ANGLE:** 스틱은 목표 기울기(최대 45°, 이 FC의 `max_angle_inclination`)이고 공기저항만 있다.
- **ALTHOLD:** 스로틀 중앙은 고도 유지, 벗어난 만큼 상승·하강(최대 2m/s)한다.
- **데드밴드:** 중앙 ±10µs (`pos_hold_deadband`)
- **모터:** INAV 쿼드 X 믹서(M1 뒤오른쪽, M2 앞오른쪽, M3 뒤왼쪽, M4 앞왼쪽)로 계산한다. 기울기를 바꾸는 순간에만 앞뒤·좌우 차이가 생긴다.
- 실제 비행 튜닝을 대신하지는 않는다. 방향·부호, 미션 흐름, 이득의 경향, 실패 상황 대응을 확인하는 용도다.

## 검증 기록 (20261003)

- **화면 태그 검출:** 헤드리스 Chrome에서 그린 태그를 AprilTag 검출기로 확인했다. ID 10으로 인식됐고, 중심 오차는 0.3px 이하였다. 화면에서 잰 오프셋(cm)은 가상 기체의 실제 오프셋과 일치했다.
- **폐루프 (보드 대신 같은 제어식을 쓰는 가짜 보드, 지연 0.3초, 옆바람 20cm/s):** 미션 전 단계를 13초에 완료했다. 처음 정렬에서 약 15cm를 지나쳤다가 7초 안에 수렴했다.
- **실제 보드 연결 시험은 아직 하지 않았다.**
